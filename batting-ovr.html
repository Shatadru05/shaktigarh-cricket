Benchmark targets

Editable standards

Target-based curves follow their configured benchmarks; CON uses its calibrated smooth curve. These are configurable local benchmarks, not universal standards.

Impact units per innings = (50+ scores + centuries) ÷ innings, so centuries receive additional credit. EXPL uses four smooth target-dependent curves with equal 25% weights: boundaries/innings, sixes/innings, boundary-run percentage, and strike rate. Each component scores 80 at its target and approaches 100 asymptotically.

Formula details

BAT and STR use their calibrated curves; CON uses a smooth logistic curve where target T maps to 90 and T−15 percentage points maps to 70. IMP uses a target-dependent exponential curve: target T maps to 90, 0.4T maps to 70, and the rating approaches 100 asymptotically without reaching it. EXP uses a smooth exponential curve. EXPL averages four smooth component curves, each 100 × (1 − 5^(−actual ÷ target)), with equal 25% weights. Impact units per innings = (50+ scores + centuries) ÷ innings. Survival compares the actual not-out rate to the position-weighted expected rate and uses the documented anchor scale; if no position innings are entered, it uses the fallback not-out-rate target. OVR is the weighted mean of all seven attributes using normalised weights.
